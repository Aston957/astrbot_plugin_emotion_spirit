## 实现细节(给后续 session 参考)

### conscience.py `_window` 语义变更总结
- **旧 (cumulative, Bug-G 根因)**: 每次 `record_*` append `self._raw_pressure` (累计值) → P95 ≈ 当前值 → 永饱和
- **新 (incremental)**: 4 个 `record_*` 事件方法 append 单次 `conscience_impact`/`severity`; `record_alignment`/`record_repair` 缓解方法**不**append; `tick_pressure` 衰减方法**不**append
- **效果**: P95 = 典型事件强度高分位, `_raw_pressure / P95` = "典型事件数" 倍数 → 自然反映压力密集度

### orchestrator delivery_mode 切换矩阵
| mode | `event.send` | `result_chain` | delay | 表情包 |
|---|---|---|---|---|
| `append` (默认) | 不调 | `chain.append(Plain)` | 失 | ✅ |
| `event_send` (保留) | 逐段调 | `=MessageChain([])` 防 double-send | 保 | ❌ (Bug-E 旧行为) |
| `delayed_append` (v1.3+) | 不调 | `chain.append` | 待 `send_delayed` API | ✅ |

### main.py `_decay_tick_loop` 设计
- `asyncio.sleep(3600)` 每小时
- 计算 `hours = (now - _last_decay_tick) / 3600.0` (累积漂移容忍)
- `tick_pressure(hours)` 调 `conscience.tick_pressure`
- log: `conscience pressure decayed hours=X.XX raw=X.XXX`
- 异常隔离: 单次 tick 失败不影响 loop 继续
- `CancelledError` 退出
