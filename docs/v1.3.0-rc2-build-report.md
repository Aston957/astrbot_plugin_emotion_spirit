## KB 设计 (conscience_params.json)

| 参数 | baseline | range | 核心权重 |
|---|---|---|---|
| acute_decay_rate_per_min | 0.12 | [0.03, 0.30] | patience/inner_coherence 降, boundary_permeability 升 |
| chronic_decay_rate_per_hour | 0.08 | [0.02, 0.20] | inner_coherence/patience/exploration_openness 降 |
| collapse_threshold | 0.75 | [0.5, 0.95] | inner_coherence/patience 升, boundary_permeability 降 |
| acute_multiplier | 1.0 | [0.5, 2.0] | expression_drive/gossip_tendency 升 |
| chronic_multiplier | 0.30 | [0.1, 0.8] | intimacy_pull/warmth_bias 升 |
| suppression_efficiency | 0.50 | [0.1, 0.9] | boundary_permeability/directness 降, inner_coherence 升 |

**语义**:
- 急性 = 瞬时冲击, 大, 快衰减 (per_min)
- 慢性 = 累计压力, 小, 慢衰减 (per_hour)
- suppression_level 调制慢性积累速度: `chronic_gain × (1 - supp × eff)`
- 高 inner_coherence/patience 人格 → 衰减快 + 阈值高 (不易崩)
- 高 boundary_permeability 人格 → 压抑效率低 (边界透, 压抑不住)

**注意**: weights 正负 + 数值是初始设想, 可微调。`baseline` 是"中性人格 (全 0.5) 时的值", 偏离中性才调制。
