## 派生提案 (起点, 验证或调)

每个 Big Five = 其 NEO-PI-R facet 对应的 13 维 dim 加权平均:

| Big Five | = 加权平均(13 维) | NEO-PI-R facet 依据 |
|---|---|---|
| **E** Extraversion | `0.25·warmth_bias + 0.25·expression_drive + 0.20·gossip_tendency + 0.15·intimacy_pull + 0.15·relational_gravity` | E1 warmth + E3 assertiveness + E2 gregariousness |
| **N** Neuroticism | `0.40·boundary_permeability + 0.35·(1−inner_coherence) + 0.25·(1−patience)` | N6 vulnerability + 低 C5 自律 + 低耐心 |
| **A** Agreeableness | `0.40·warmth_bias + 0.30·directness + 0.30·relational_gravity` | A6 tender-mindedness + A2 straightforwardness + A4 compliance |
| **C** Conscientiousness | `0.65·inner_coherence + 0.35·patience` | C5 self-discipline + C6 deliberation |
| **O** Openness | `0.40·curiosity + 0.35·exploration_openness + 0.25·perception_acuity` | O5 ideas + O4 actions + O2 aesthetics |

注意: `warmth_bias` 同时进 E(0.25)和 A(0.40) — NEO-PI-R 里 warmth 是 E1 但语义含 A6 tender-mindedness, E/A 通过 warmth 相关是心理学事实, 不是 bug. N 用 `(1−inner_coherence)` 反向项 (低一致 = 不稳定).
