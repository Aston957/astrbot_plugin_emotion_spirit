## 背景

Y-转绿验收发现 **Bug-G 回归**. 小模型在 `main.py:493` 用**赋值** (`=`) 替代 plan 要求的 **update** (`self._baseline_personality.update(...)`), 把 `_baseline_personality` 从 nested dict `{deep:{...}, surface:{...}}` 变成 flat dict (无 deep/surface key).

后果: `main.py:501-505` 的 ConscienceTracker 路径 `deep = self._baseline_personality.get("deep", {})` 拿到空 dict → `full_personality = {}` → `if full_personality:` False → **`set_personality` 不调** → ConscienceTracker 不随人格变化 → **Bug-G 回归** (rc.4 刚修好的 bug 又回来了).

`main.py:819-824` (重建 conscience 路径) 同样受影响.

**测试漏洞**: 9 个测试全过但没抓到, 因为都是 helper 单元测试 + LifeAgent 单元测试, 没有一个测 `main.py` 的 `_update_baseline` → ConscienceTracker 集成路径.
