## 修法策略

**核心原则**: 不改 13 个只读 consumer (Y-0 哲学: 派生注入修活), 在 caller 端注入派生 Big Five.

**抽 helper** (放 `emotion_spirit/utils/persona_profiles.py`, 跟 `to_big_five` 一起):

```python
def personality_with_big_five(nested: dict) -> dict[str, float]:
    """nested {deep, surface} → flat 13 维 + 派生 Big Five (top-level).

    给 Big Five consumer 的统一入口. 拍平 13 维 + 注入 to_big_five 派生值.
    缺 deep/surface 用空 dict 兜底.
    """
    flat = {**nested.get("deep", {}), **nested.get("surface", {})}
    flat.update(to_big_five(flat))
    return flat
```
